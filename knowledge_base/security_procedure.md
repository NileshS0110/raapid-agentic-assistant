INFORMATION SECURITY INCIDENT PROCEDURE

Employees must immediately report suspected security incidents.

Examples include:
- Phishing emails
- Lost or stolen company devices
- Unauthorized access
- Accidental exposure of confidential information

Employees should raise a high-priority IT security ticket.

Employees must not share passwords or authentication codes.

Security incidents involving suspected data exposure must be escalated to the Information Security team.

Employees should not investigate suspected breaches independently or delete potential evidence.
